# Famous Last Words: The Funniest Epitaph

A program that writes one one-line tombstone epitaph (at most 150 characters) to `/output/entry.txt` for the [make.fun bounty](https://make.fun/bounty/u-riidzhsn-famous-last-words-the-funniest-epitaph-ff177406).

The line: *"Good news: I finally lost weight. Bad news: all of it."* (54 characters)

Run: `node main.ts` (Node 22). No network, no dependencies.
